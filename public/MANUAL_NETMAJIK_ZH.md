## 1. 引言与系统权限

NetMajik 是一款专为系统管理员、网络工程师和 IT 支持人员打造的桌面应用程序。它可以帮助您管理 Windows 网络适配器、在几秒钟内配置静态或 DHCP IP 配置文件、绘制本地网络拓扑并诊断网络故障。

> **管理员权限**：由于 NetMajik 直接与 Windows TCP/IP 协议栈交互，因此必须以**管理员身份运行**应用程序，以便应用 IP 配置文件、重启到 BIOS 或启用/禁用网卡。

---

## 2. 侧边栏与网络接口

- **网卡列表**：自动检测以太网 (LAN)、Wi-Fi 和虚拟网卡 (VPN、Docker、VMware)。
- **操作控制**：一键禁用/启用网卡，选择当前活动接口。

---

## 3. IP 配置文件管理与文件夹

- **配置文件创建**：配置静态 IP、DHCP、子网掩码、网关、DNS 以及多 IP 别名。
- **自动 IP 冲突解决**：当目标静态 IP 被其他接口占用时，NetMajik 会自动将冲突接口切换为 DHCP。
- **文件夹拖拽排序**：支持在文件夹内部拖拽卡片以调整优先级。

---

## 4. 诊断工具与出厂凭据库

- **Ping & Traceroute**：实时延迟图表与路径跟踪。
- 包含海康威视、大华、思科等厂商的出厂默认密码，并支持 *Smart Connect* 快速加入子网功能。
